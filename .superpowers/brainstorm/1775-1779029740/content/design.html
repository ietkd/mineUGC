5 个功能的设计方案

混合方式：简单功能用聊天，复杂功能用子 Inventory

① 套装 (Set Bonus) — 聊天输入

最简单——就是一个名字字符串。

点击按钮 → chat: "输入套装名称" → 输入 "烈焰套装" → 完成

② 属性 (Attributes) — 子界面

Map<String, Double> 键值对编辑。

54 格界面
· 已有属性以物品展示
· 点击单个属性 = 删除
· 🟢 添加按钮 → chat: "damage 5.0"
· 🔴 返回按钮
dmg
spd
arm

③④ 技能 & 被动 — 两层子界面

因为每个技能/被动有多个字段（type, cooldown 等），用两层界面：

第一层 (列表): 54 格，显示所有技能 key
  · 点击已有技能 → 打开编辑界面
  · 🟢 添加 → chat: "输入技能key (如 right_click)"
  · 🔴 返回

第二层 (编辑): 36 格
  · 显示当前技能名
  · Type 字段 → chat 输入
  · Cooldown 字段 → chat 输入 (数字)
  · Mana Cost 字段 → chat 输入 (数字)
  · 🗑️ 删除此技能
  · 🔴 返回列表

⑤ 配方 (Recipe) — 子界面

Shape (3字符串) + Ingredients (字符→物品名)。

54 格界面：
· 显示当前 3×3 形状预览
· 显示材料映射 (A=DIAMOND, B=STICK)
· 🟢 编辑形状 → chat: "ABA,AAA,CDC"
· 🟢 编辑材料 → chat: "A=DIAMOND,B=STICK"
· 🔴 返回
