GUI 编辑器 & 命令系统

命令结构

/ugc item list # 列出所有物品
/ugc item give <id> # 获取物品
/ugc item reload # 手动触发热加载
/ugc edit # 打开 GUI 编辑器
/ugc reload # 重新加载所有资产

GUI 实现原则

• 所有编辑项点开后弹子菜单 / 虚拟键盘输入

• 保存时直接写回 YAML 文件，触发热加载

• 道具预览在编辑界面中直接展示成品物品

• 所有界面可点 [X] 或按 ESC 关闭，不阻塞玩家操作
