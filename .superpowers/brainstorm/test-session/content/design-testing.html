错误处理 & 测试策略

错误处理原则

# YAML 加载时 = 严格验证，出错拒绝加载
# 运行时 = 静默降级，不崩服务器

YAML 验证失败 → 控制台报错 + 跳过该文件，不影响其他物品
物品 ID 重复 → 后加载的覆盖先加载的，告警日志
技能执行异常 → 捕获异常，提示玩家，不崩 tick
GUI 输入非法 → 当场提示，不允许保存到 YAML
SQLite 连接失败 → 运行时降级为内存缓存，不影响核心功能

测试策略

单元测试 — JUnit 5
• ItemDefinition 解析 (YAML → POJO)
• AttributeApplier 数值计算
• SetBonusTracker 套装检测
• AssetRegistry 注册/替换/查找

集成测试 — 启动 Paper 测试环境
• 物品给予玩家、手持检测、生效
• 技能触发逻辑
• 热加载流程端到端

不需要测试的
• GUI 交互逻辑 (Bukkit GUI 难模拟，靠人工验收)
