Phase 1 设计 — 模块结构

Gradle 多模块项目
mineUGC/
├── build.gradle (root — 聚合所有子模块)
├── settings.gradle (include 所有子模块)
├── 📦 core/
│ └── src/main/java/org/mineUGC/
│ ├── models/ — UgcAsset 接口, ItemDefinition 模型类
│ ├── registry/ — AssetRegistry (注册、查找、热替换)
│ ├── events/ — 自定义 Bukkit 事件 (AssetLoadEvent, etc.)
│ └── commands/ — 基础命令框架
├── 📦 storage/
│ └── src/main/java/org/mineUGC/storage/
│ ├── yaml/ — YamlItemLoader, YamlWatcher (热加载)
│ └── sqlite/ — DatabaseManager, PlayerDataDAO
├── 📦 items/
│ └── src/main/java/org/mineUGC/items/
│ ├── attributes/ — AttributeApplier (数值映射到 NBT)
│ ├── abilities/ — AbilityExecutor (主动技能)
│ ├── passives/ — PassiveEffect (被动效果)
│ ├── sets/ — SetBonusTracker
│ ├── crafting/ — CustomRecipeManager
│ └── listeners/ — Bukkit 监听器 (右键、穿戴、攻击检测)
├── 📦 gui/
│ └── src/main/java/org/mineUGC/gui/
│ └── editor/ — 物品编辑 GUI 界面
└── 📦 plugin/ (入口模块 — 唯一有 plugin.yml 的模块)
└── src/main/java/org/mineUGC/plugin/
└── MineUGC.java (extends JavaPlugin, 启动所有模块)

依赖关系

plugin → core ← storage → SQLite

plugin → items → core

plugin → gui → items, core

core 对其它模块无依赖 — 这是整个系统的核心契约
