热加载流程

# 1. FileWatcher 检测到 .yml 变更
# 2. YamlWatcher 解析新 YAML → ItemDefinition
# 3. 验证字段合法性（material 是否存在、数值是否合理）
# 4. AssetRegistry.replace(id, newDefinition)
# 5. 触发 AssetReloadEvent (Bukkit 事件)
# 6. ItemManager 更新缓存
# 7. 玩家手中的旧物品下次 tick 刷新为新版本

更新玩家手中物品的策略

热加载后，玩家已有的旧物品怎么办？

1

懒更新

玩家手持物品时检测 ID，若版本过旧则自动替换为新版。性能开销最小，但不立即生效

2

主动推送

热加载后扫描所有在线玩家背包，替换对应物品。立即生效，但大规模扫描有性能开销

3

主动推送 + 懒更新兜底

先扫描在线玩家更新，不在线的等上线后懒更新
